# Уитстон шифры — модельдеу және криптоталдау

Бұл — телефондар мен ноутбуктердің браузерінде ашылатын адаптивті веб-қосымша және PWA негізі.

## Іске қосу

- `index.html` файлын браузерде ашып, негізгі функцияларын тексеруге болады.
- PWA орнату және офлайн кэш үшін жобаны HTTPS арқылы жариялау қажет (мысалы, GitHub Pages).
- Three.js кітапханасы CDN арқылы жүктеледі; интернет жоқ кезде негізгі шифрлау/криптоталдау интерфейсі жұмыс істей береді, бірақ 3D-анимация көрінбеуі мүмкін.

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа repository жасаңыз.
2. ZIP ішіндегі файлдарды шығарып, барлығын repository-дің негізгі (root) қалтасына жүктеңіз.
3. **Settings → Pages** бөліміне кіріңіз.
4. **Deploy from a branch** таңдаңыз.
5. Branch ретінде `main`, қалта ретінде `/ (root)` таңдап, **Save** басыңыз.
6. GitHub берген Pages сілтемесін телефоннан және ноутбуктен ашыңыз.

## Телефонға орнату

- Android/Chrome: жарияланған сайтты ашыңыз → браузер мәзірі → **Install app** немесе **Add to Home screen**.
- iPhone/Safari: сайтты ашыңыз → **Share** → **Add to Home Screen**.

> Ескерту: `service-worker.js` және PWA орнату мүмкіндіктері `file://` арқылы емес, HTTPS сайтында (немесе localhost-та) жұмыс істейді.
